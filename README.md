# IDS-project-using-ML-algorthim-
compartive analysis of network intrusion detection using ML and traditional methods

# Source Code

This folder contains the Python source code for my Machine Learning Network Intrusion Detection System (NIDS).

## Project Purpose

The project aims to analyze network traffic and detect malicious activities using machine learning techniques.

## Planned Files

- data_loader.py — Load and prepare the dataset.
- preprocessing.py — Clean and preprocess network traffic data.
- train_model.py — Train machine learning models.
- evaluate_model.py — Evaluate model performance.

## Dataset

The primary dataset used in this project is UNSW-NB15.
